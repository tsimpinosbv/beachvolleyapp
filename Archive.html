Ρύθμιση αρχείου (μία φορά)

  1. Στο GitHub πάτα + → New repository.
  2. Όνομα: bv-supervisor-archive, επίλεξε Private και τσέκαρε Add a README file. Πάτα Create repository.
  3. Άνοιξε τα κλειδιά σου (tokens), πάτα το κλειδί BV Supervisor Tools → Edit.
  4. Στο Repository access πρόσθεσε και το bv-supervisor-archive και πάτα Update. Το κλειδί μένει ίδιο, δεν χρειάζεται να το ξαναβάλεις.
  5. Γύρνα εδώ και πάτα ↻ Ανανέωση.
Για να μπει κάτι στο αρχείο, πάτα «Αποθήκευση στο αρχείο» στην Αναφορά Supervisor ή στο Φύλλο Πληρωμής Επάθλων. «Άνοιγμα» το φέρνει στην εφαρμογή για διόρθωση· μετά ξαναπάτα «Αποθήκευση στο αρχείο» για να ενημερωθεί.
