1. Εγκατάσταση της εφαρμογής

Το BV Supervisor Tools εγκαθίσταται ως ξεχωριστή εφαρμογή, ανεξάρτητη από το Check Mate Suite.

Android (Chrome)

  1. Άνοιξε το tsimpinosbv.github.io/beachvolleyapp/ σε Chrome.
  2. Πάτα το κουμπί «Εγκατάσταση εφαρμογής» στο μπλε πάνω μέρος της αρχικής σελίδας.
    • Αν δεν εμφανίζεται: μενού ⋮ πάνω δεξιά → «Εγκατάσταση εφαρμογής» / «Προσθήκη στην αρχική οθόνη».
  3. Επιβεβαίωσε. Εμφανίζεται εικονίδιο «Supervisor Tools» στην αρχική οθόνη και ανοίγει σαν κανονική εφαρμογή.

iPhone / iPad (Safari)

  1. Άνοιξε τη διεύθυνση σε Safari.
  2. Πάτα Κοινοποίηση (□↑) → «Προσθήκη στην οθόνη Αφετηρίας» → Προσθήκη.

Υπολογιστής (Chrome / Edge)

Πάτα «Εγκατάσταση εφαρμογής» στην αρχική σελίδα ή το εικονίδιο εγκατάστασης στη γραμμή διευθύνσεων.

Αν είχες εγκαταστήσει παλιότερη έκδοση πριν από τις 9/11/2026, απεγκατάστησέ την και εγκατάστησέ την ξανά με τα παραπάνω βήματα, ώστε να εμφανίζεται ως ξεχωριστή εφαρμογή.

2. Πριν κάνεις αλλαγές στο GitHub

  • Να είσαι συνδεδεμένος στο GitHub με τον λογαριασμό tsimpinosbv.
  • Στο κινητό άνοιξε το GitHub στον browser, όχι στην εφαρμογή GitHub: η εφαρμογή δεν ανεβάζει αρχεία.

Δύο κανόνες που γλιτώνουν τα περισσότερα λάθη:

  1. Το όνομα του αρχείου πρέπει να είναι ακριβώς ίδιο με αυτό που αντικαθιστάς, με τα ίδια κεφαλαία/πεζά. Το ranking.xlsx δεν είναι το ίδιο με το Ranking.xlsx.
  2. Το αρχείο πρέπει να μπει στον σωστό φάκελο. Πριν πατήσεις «Upload files», άνοιξε πρώτα τον φάκελο όπου πρέπει να πάει.

3. Ενημέρωση βαθμολογίας (Ranking.xlsx)

Ανεβάζεις το νέο Ranking.xlsx στη ρίζα του repository και αντικαθιστά το παλιό. Βαθμολογία και έπαθλα ενημερώνονται μαζί, από τα φύλλα MEN, WOMEN, MEN PRIZES και WOMEN PRIZES.

Από την εφαρμογή (ο πιο εύκολος τρόπος)

  1. Άνοιξε τη Βαθμολογία στην εφαρμογή και πάτα Αρχείο.
  2. Διάλεξε το νέο Excel. Το όνομα του αρχείου δεν έχει σημασία: δημοσιεύεται πάντα ως Ranking.xlsx.
  3. Έλεγξε ότι η βαθμολογία φαίνεται σωστά (και το πορτοκαλί μήνυμα για ονόματα, αν εμφανιστεί).
  4. Πάτα Δημοσίευση στο GitHub → επιβεβαίωσε. Σε 1–2 λεπτά τη βλέπουν όλοι.

Την πρώτη φορά σε κάθε συσκευή ζητά ένα κλειδί πρόσβασης (token) του GitHub:

  1. Πάτα τον σύνδεσμο σελίδα δημιουργίας token στο παράθυρο που ανοίγει (πρέπει να είσαι συνδεδεμένος ως tsimpinosbv).
  2. Expiration: διάλεξε διάρκεια, π.χ. 1 χρόνο.
  3. Repository access: Only select repositories → beachvolleyapp.
  4. Permissions: το Contents να είναι Read and write (είναι ήδη επιλεγμένο).
  5. Generate token → αντέγραψε το κλειδί (github_pat_…) → επικόλλησέ το στην εφαρμογή → Αποθήκευση και δημοσίευση.

Το κλειδί μένει αποθηκευμένο μόνο σε εκείνη τη συσκευή και επιτρέπει αλλαγές μόνο στο beachvolleyapp. Μην το δίνεις σε άλλους. Όταν λήξει, η εφαρμογή σου ζητά νέο. Αν χάσεις τη συσκευή, διάγραψε το κλειδί από github.com/settings/personal-access-tokens.

Από υπολογιστή μέσω GitHub

  1. Στο Excel, αποθήκευσε το αρχείο ως Ranking.xlsx (ακριβώς έτσι). Κράτα τα ονόματα των φύλλων όπως είναι.
  2. Άνοιξε το repository. Μείνε στην κεντρική σελίδα, όχι μέσα σε φάκελο.
  3. Πάτα Add file → Upload files.
  4. Σύρε το Ranking.xlsx μέσα στο πλαίσιο, ή πάτα choose your files και διάλεξέ το.
  5. Κάτω, στο Commit changes, γράψε μια σύντομη περιγραφή, π.χ. «Βαθμολογία μετά το Athens Finals».
  6. Πάτα το πράσινο Commit changes.

Από κινητό μέσω GitHub

  1. Άνοιξε το repository σε Chrome ή Safari.
  2. Πάτα το + ή το … πάνω από τη λίστα αρχείων → Upload files. Αν δεν φαίνεται, άνοιξε το μενού του browser → Έκδοση για υπολογιστές (Desktop site).
  3. Πάτα choose your files και διάλεξε το Ranking.xlsx από τα Αρχεία/Λήψεις του κινητού.
  4. Γράψε περιγραφή και πάτα Commit changes.

Δοκιμή χωρίς δημοσίευση: το κουμπί Αρχείο φορτώνει ένα xlsx μόνο στη δική σου συσκευή (δουλεύει και χωρίς σύνδεση). Δεν το βλέπουν οι άλλοι αν δεν πατήσεις «Δημοσίευση στο GitHub». Μένει ενεργό μέχρι να πατήσεις Ανανέωση ή Επαναφορά online δεδομένων.

Αν μετά το ανέβασμα εμφανιστεί το πορτοκαλί μήνυμα για ονόματα που δεν ταιριάζουν, διόρθωσε τη γραφή τους στο Excel ώστε να είναι ίδια στα φύλλα πόντων και επάθλων, και ανέβασέ το ξανά.

4. Αλλαγή πινάκων βαθμολογίας (Υπολογισμός Βαθμολογίας)

Οι πίνακες του «Υπολογισμός βαθμολογίας με δυναμικό συντελεστή» διαβάζονται από το αρχείο PointSystem.xlsx. Όταν αλλάξει το σύστημα βαθμολόγησης, αλλάζεις μόνο αυτό το αρχείο.

  1. Άνοιξε τον Υπολογισμό Βαθμολογίας και κατέβα στο πλαίσιο «Πίνακες βαθμολογίας (αρχείο)».
  2. Πάτα Λήψη δείγματος (PointSystem.xlsx). Κατεβαίνει το τρέχον αρχείο με όλους τους πίνακες.
  3. Στο Excel, κάθε φύλλο είναι ένα ταμπλό (οδηγίες στο φύλλο ΟΔΗΓΙΕΣ):
    • Πάνω, στη στήλη B: ΤΑΜΠΛΟ (όνομα κουμπιού), ΣΥΝΤΕΛΕΣΤΗΣ, ΠΟΣΟΣΤΟ ΑΘΛΗΤΗ (0,5 = μισοί βαθμοί), ΘΕΣΗ 3/4 ΧΩΡΙΣΤΑ (κενά αν δεν ισχύει), ΑΝΟΙΓΕΙ ΠΡΩΤΟ (ΝΑΙ σε ένα ταμπλό).
    • Κάτω από τη γραμμή ΘΕΣΗ / ΒΑΣΗ: η θέση και οι βαθμοί ομάδας πριν τον συντελεστή.
    • Για νέο ταμπλό αντέγραψε ένα φύλλο· για διαγραφή, σβήσε το φύλλο. Η σειρά των φύλλων είναι η σειρά των κουμπιών.
  4. Πάτα Ανέβασμα αρχείου και διάλεξε το Excel. Αν έχει λάθη (π.χ. γράμματα αντί για αριθμό), εμφανίζεται ποιο φύλλο και ποια γραμμή.
  5. Οι νέοι πίνακες φαίνονται αμέσως για έλεγχο, μόνο σε εσένα. Πάτα Δημοσίευση στο GitHub για να τους δουν όλοι, ή Ακύρωση.

Χρησιμοποιεί το ίδιο κλειδί GitHub με τη Βαθμολογία (ενότητα 3).

5. Αρχική Λίστα (Entry List) τουρνουά

Η κάρτα «Αρχική Λίστα» φτιάχνει τη λίστα συμμετοχής με βαθμούς και σειρά αυτόματα, από το Ranking.xlsx.

  1. Συμπλήρωσε όνομα τουρνουά και ημερομηνίες (μπαίνουν στον τίτλο του Excel).
  2. Διάλεξε μέθοδο βαθμών: «Σύνολο σεζόν» ή «Καλύτερα Ν αποτελέσματα», και μέχρι ποιο τουρνουά μετράνε οι βαθμοί.
  3. Αν θέλεις χωρισμό, βάλε θέσεις κύριου ταμπλό και wild cards. Οι ομάδες σημειώνονται MD ή Q.
  4. Πρόσθεσε τις ομάδες:
    • Εισαγωγή Excel δηλώσεων: ανέβασε απευθείας την εξαγωγή δηλώσεων της ομοσπονδίας (στήλες ΕΠΙΘΕΤΟ, ΟΝΟΜΑ, ΦΥΛΟ, ΕΠΙΘΕΤΟ/ΟΝΟΜΑ ΣΥΜΠΑΙΚΤΗ, ΗΜΕΡΟΜΗΝΙΑ ΑΙΤΗΣΗΣ). Χωρίζει άνδρες/γυναίκες, αναγνωρίζει ονόματα σε greeklish ή με ανακατεμένο όνομα/επώνυμο, ενώνει τις διπλές δηλώσεις (όταν δηλώνουν και οι δύο συμπαίκτες) και βάζει σειρά με την ημερομηνία αίτησης. Δηλώσεις με κατάσταση «απορρίφθηκε/ακυρώθηκε» παραλείπονται. Email, ΑΜΚΑ και τηλέφωνα δεν διαβάζονται.
    • Δέχεται και απλό Excel με φύλλα MEN και WOMEN και δύο ονόματα ανά γραμμή (ή «Όνομα 1 / Όνομα 2»). Το κουμπί Πρότυπο δηλώσεων κατεβάζει έτοιμο πρότυπο.
    • Επικόλληση λίστας: μία ομάδα ανά γραμμή.
    • Χειροκίνητα: με αυτόματη συμπλήρωση ονομάτων από τη βαθμολογία.
  5. Έλεγξε το πορτοκαλί πλαίσιο: αθλητές σε δύο ομάδες, ονόματα που δεν βρέθηκαν (0 βαθμοί) και αντιστοιχίσεις κατά προσέγγιση (≈). Διόρθωσε ένα όνομα πατώντας πάνω του.
  6. Σε ισοβαθμία η σειρά είναι η σειρά δήλωσης (ημερομηνία αίτησης)· άλλαξέ τη με τα βελάκια ↑ ↓.
  7. Πάτα Λήψη Excel: βγαίνει αρχείο με φύλλα MEN και WOMEN στη μορφή του ENTRY LIST (στήλες ΑΘΛΗΤΗΣ 1, ΑΘΛΗΤΗΣ 2, ΒΑΘΜ, ΣΥΝΟΛΟ).

Η λίστα αποθηκεύεται αυτόματα στη συσκευή σου, οπότε μπορείς να κλείσεις και να συνεχίσεις αργότερα.

6. Λίστα Ελέγχου και Πληρωμές

Λίστα Ελέγχου Επόπτη

  1. Πάτα + Νέο και δώσε όνομα τουρνουά. Κάθε τουρνουά κρατά τα δικά του ✓ και σημειώσεις.
  2. Οι έλεγχοι είναι σε 5 φάσεις: Πριν, Άφιξη, Κάθε ημέρα, Τελικοί, Μετά. Πάτα μια φάση για να ανοίξει.
  3. Τσέκαρε ό,τι έγινε. Το «Μόνο όσα μένουν» κρύβει τα ολοκληρωμένα.
  4. Στο τέλος κάθε φάσης πρόσθεσε δικούς σου ελέγχους (μένουν για όλα τα τουρνουά) και σημειώσεις.
  5. Με το επάνω μενού αλλάζεις τουρνουά. Υπάρχει και Εκτύπωση.

Συμμετοχές & Πληρωμές

  1. Φτιάξε πρώτα την Αρχική Λίστα στην ίδια συσκευή.
  2. Βάλε παράβολο και διάλεξε αν είναι ανά ομάδα ή ανά αθλητή.
  3. Πάτα Από την Αρχική Λίστα. Αν η λίστα αλλάξει, ξαναπάτα το: μπαίνουν μόνο οι νέες ομάδες.
  4. Σε κάθε ομάδα πάτα Χρωστάει / Μετρητά / Κατάθεση / Απαλλαγή. Για μερική πληρωμή γράψε το ποσό. Για άλλη οφειλή σε μία ομάδα, γράψ' την στο πεδίο «Οφειλή».
  5. Πάνω βλέπεις πόσα μαζεύτηκαν, το υπόλοιπο και πόσες ομάδες χρωστάνε. Τα φίλτρα δείχνουν μόνο όσους χρωστάνε ή πλήρωσαν.
  6. Πάτα Excel για σύνοψη και λίστα ανά κατηγορία. Για νέο τουρνουά πάτα Νέο τουρνουά.

Τα στοιχεία και των δύο μένουν μόνο στη συσκευή σου.

7. Προσθήκη αρχείων στα «Αρχεία Τουρνουά» και «Διεθνείς Διοργανώσεις»

Τα αρχεία σε αυτούς τους φακέλους εμφανίζονται μόνα τους στην εφαρμογή. Δεν αλλάζεις καμία σελίδα.

Κάρτα στην εφαρμογή Φάκελος στο GitHub
Αρχεία Τουρνουά files
Διεθνείς Διοργανώσεις International
  1. Άνοιξε το repository.
  2. Πάτα τον φάκελο, π.χ. files. Βεβαιώσου ότι πάνω γράφει beachvolleyapp / files /.
  3. Πάτα Add file → Upload files.
  4. Σύρε μέσα ένα ή περισσότερα αρχεία (xls, xlsx, xlsm, pdf, doc, docx).

  5. Γράψε περιγραφή, π.χ. «Νέο ταμπλό 16 ομάδων», και πάτα Commit changes.

  6. Το όνομα του αρχείου είναι αυτό που βλέπουν όλοι στη λίστα. Δώσε καθαρό όνομα πριν το ανεβάσεις.

  7. Για νέα έκδοση ενός αρχείου, ανέβασέ το με ακριβώς το ίδιο όνομα: αντικαθιστά το παλιό. Με άλλο όνομα θα υπάρχουν και τα δύο.
  8. Το GitHub δέχεται αρχεία έως 25 MB μέσω browser.

8. Αλλαγή σελίδας της εφαρμογής

Αντικατάσταση ολόκληρου αρχείου (π.χ. νέο Ranking.html που σου έστειλε το Claude)

  1. Άνοιξε το repository, στον φάκελο όπου βρίσκεται το αρχείο. Οι σελίδες (index.html, Ranking.html, Prices.html κ.λπ.) είναι στη ρίζα.
  2. Add file → Upload files.
  3. Σύρε μέσα το νέο αρχείο, με ακριβώς το ίδιο όνομα.
  4. Περιγραφή → Commit changes.

Μικρή αλλαγή κειμένου απευθείας στο GitHub (π.χ. ένας τίτλος ή μια λέξη)

  1. Πάτα το αρχείο στη λίστα, π.χ. index.html.
  2. Πάτα το μολύβι ✏️ (Edit this file) πάνω δεξιά.
  3. Βρες το κείμενο με Ctrl+F (Mac: Cmd+F) και άλλαξέ το. Άλλαξε μόνο το κείμενο ανάμεσα στα > και <, όχι τον κώδικα γύρω του.
  4. Πάτα Commit changes… → γράψε περιγραφή → Commit changes.

Αν αλλάξεις εικόνα ή εικονίδιο (φάκελος icons/), άνοιξε και το service-worker.js με το μολύβι και ανέβασε κατά ένα τον αριθμό στη γραμμή const CACHE_VERSION = 'bv-tools-v15'; (π.χ. σε v16). Αλλιώς οι εγκατεστημένες εφαρμογές κρατούν την παλιά εικόνα. Για σελίδες HTML και το Ranking.xlsx δεν χρειάζεται.

9. Διαγραφή ή μετονομασία αρχείου

Διαγραφή

  1. Πάτα το αρχείο στη λίστα.
  2. Πάτα το … πάνω δεξιά → Delete file.
  3. Commit changes… → Commit changes.

Μη διαγράφεις index.html, manifest.json, service-worker.js, offline.html ή τον φάκελο icons/: χωρίς αυτά η εφαρμογή σταματά να εγκαθίσταται ή να ανοίγει.

Μετονομασία

  1. Πάτα το αρχείο → μολύβι ✏️ (Edit this file).
  2. Πάνω, στο πλαίσιο με το όνομα, άλλαξε το όνομα.
  3. Commit changes… → Commit changes.

Για αρχεία Excel/PDF το μολύβι δεν εμφανίζεται. Κατέβασέ το, μετονόμασέ το στον υπολογιστή, ανέβασέ το με το νέο όνομα και διάγραψε το παλιό.

Αναίρεση λάθους: στο repository πάτα Commits (το ρολόι πάνω από τη λίστα αρχείων) για να δεις όλες τις αλλαγές. Κάθε παλιά έκδοση αρχείου μένει εκεί. Αν κάτι χαλάσει, πες στο Claude «φέρε πίσω την προηγούμενη έκδοση του X».

10. Έλεγχος ότι η αλλαγή βγήκε online

  1. Στο repository πάτα την καρτέλα Actions. Η πρώτη εργασία «pages build and deployment» δείχνει κίτρινο κύκλο όσο τρέχει και πράσινο ✓ όταν τελειώσει. Κόκκινο ✗ σημαίνει σφάλμα: πες το στο Claude.
  2. Άνοιξε την εφαρμογή και κάνε ανανέωση της σελίδας.
  3. Για τη βαθμολογία, πάτα Ανανέωση μέσα στη σελίδα Βαθμολογίας. Η ημερομηνία «Ενημερώθηκε» πρέπει να αλλάξει.

Στο κινητό με εγκατεστημένη την εφαρμογή: άνοιξέ την με σύνδεση στο internet, κλείσε την εντελώς και άνοιξέ την ξανά. Η δεύτερη φορά δείχνει τη νέα έκδοση.

Αν βλέπεις ακόμα «Τοπικό αρχείο» στη Βαθμολογία, πάτα Επαναφορά online δεδομένων: είναι ενεργό ένα xlsx που είχες φορτώσει με το κουμπί Αρχείο.

11. Αλλαγές μέσω Claude και συχνά προβλήματα

Για αλλαγές στη λειτουργία ή στην εμφάνιση της εφαρμογής, ζήτα τις από το Claude στο project BV Tools. Το Claude έχει πρόσβαση εγγραφής στο repository, οπότε κάνει τις αλλαγές και τις ανεβάζει μόνο του. Εσύ ελέγχεις μόνο το αποτέλεσμα (ενότητα 10).
